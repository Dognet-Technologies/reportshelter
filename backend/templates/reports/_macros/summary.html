Recommendations

{{ _ci('recommendations') }} {% if audience == 'executive' %} {# ── EXECUTIVE: strategic, program-level actions ── #}

To address the security risk identified during this assessment, the following strategic actions are recommended for {{ project.client_name or "the organization" }}.

    {% if exec_metrics.immediate_action > 0 %}
  1. Immediate risk mitigation — {{ exec_metrics.immediate_action }} Critical/High finding{{ "s" if exec_metrics.immediate_action != 1 else "" }} require{{ "" if exec_metrics.immediate_action != 1 else "s" }} priority remediation. Assign ownership and set a target resolution date within 30 days.
    2. {% endif %}
  2. Establish a remediation programme — Create a tracked remediation roadmap with clear owners, deadlines, and executive-level reporting on progress.
  3. Invest in continuous security assurance — Commission periodic assessments (quarterly/annually) and implement continuous monitoring to detect regressions.
  4. Security awareness — Ensure staff receive regular training appropriate to their role, with particular focus on social engineering and phishing risks.
  5. Governance and policy review — Validate that security policies, patch management procedures, and access control frameworks align with current risk exposure.

    {% if severity_counts.get('critical', 0) > 0 or severity_counts.get('high', 0) > 0 %}
  1. Prioritize remediation of Critical and High severity vulnerabilities immediately. Refer to the Detailed Findings and Remediation Plan sections for specific guidance.
    2. {% endif %}
  2. Establish a patch management process aligned with vendor advisories and CVSS scores.
  3. Implement continuous security monitoring (SIEM, IDS/IPS) and schedule periodic assessments.
  4. Enforce the principle of least privilege across all systems and service accounts.
  5. Conduct security awareness training with emphasis on phishing, credential hygiene, and incident reporting.
  6. Integrate security testing (SAST, DAST, dependency scanning) into the CI/CD pipeline.
